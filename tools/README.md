# tools

## For decomp

- `matt-kempster/m2c`: `uv tool install git+https://github.com/matt-kempster/m2c`

- `decomp-permuter`: `git clone https://github.com/simonlindholm/decomp-permuter` and set `DECOMP_PERMUTER` in your environment to the clone path. (e.g. `DECOMP_PERMUTER="$HOME/decomp-permuter"`)
